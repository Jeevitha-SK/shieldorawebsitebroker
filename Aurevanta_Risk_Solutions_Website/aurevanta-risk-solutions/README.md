# Aurevanta Risk Solutions — Commercial Property Insurance Broker Website

A responsive, multi-page HTML/CSS/JavaScript demonstration project built around the Commercial Property Insurance Broker brief.

## Open locally
1. Extract the ZIP file.
2. Open the `aurevanta-risk-solutions` folder.
3. Double-click `index.html` to open the Home Page 1.
4. Use the top navigation and footer to explore the pages.

For a better development workflow, open the folder in VS Code and use a local static server/Live Server extension.

## Included pages
- `index.html` — Home Page 1, general services landing
- `home-2.html` — Home Page 2, commercial property niche landing
- `about.html` — About Us
- `services.html` — Services
- `service-details.html` — Service Details and illustrative comparison table
- `blog.html` — searchable/filterable blog listing
- `blog-details.html` — full blog article with related links
- `contact.html` — validated demo contact form and map placeholder
- `pricing.html` — illustrative coverage-planning options, not insurance premiums
- `login.html` — demo client login
- `register.html` — demo registration
- `client-dashboard.html` — sample quote comparison, claims status, and policy document list
- `admin-dashboard.html` — sample analytics, users, inquiries, and CSV export
- `404.html` — not-found page
- `maintenance.html` — coming-soon/maintenance page

## Shared assets
- `assets/css/styles.css` — responsive design system, light/dark themes, RTL styles
- `assets/js/app.js` — shared header/footer, page content, demo interactions
- `assets/images/aurevanta-logo.svg` — reusable logo used in header and footer
- `assets/images/commercial-building.svg` — locally included illustrative hero image

## Demonstration limitations
This is a front-end template. Login/register interactions are not secure authentication. Form submissions are not sent to a server. Client/admin data is fictional sample data. Policy documents are placeholders, and quote/claims status is not connected to insurers. A production release needs a backend, database, secure authentication/authorization, secure file storage, validation, privacy/security review, and genuine business contact/map details. Replace all demo text and confirm company/legal/insurance wording before public launch.

The site uses a Google Fonts import when internet is available; it falls back to local system fonts if not.
